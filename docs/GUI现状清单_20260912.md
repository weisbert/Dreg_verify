# Dreg_verify GUI 现状清单（2026-09-12，opus 调研，真实 windows 平台截图在 ../gui_inventory/）

## 0. 一句话现状
gui.py 7325 行、2 个界面类（SignalView 75 方法 / MainWindow 193 方法）、6 个顶层 tab。其中 5 个 tab 是同一个 SignalView 类的 5 个实例（只换 provider），第 6 个『排查(旧)』是一套完全独立、功能重叠的旧实现。

## 1. 结构
```
MainWindow  标题="Dreg_verify — wr_rf_tc.sv 生成器 + 测试项编辑"  初始 1360×800
├─ 共享路径栏：Excel: path_edit | 浏览…(Ctrl+O) | 加载(Ctrl+L)
```

## 5. 工作流（Topout 主路径）
| # | 步骤 | 必需 | 备注 |
|---|---|---|---|
| 1 | 浏览…→选 xlsx→加载 | 必 | 记住上次路径但不自动加载 |
| 2 | 落 Topout 视图，全表默认全勾 | 自动 | 状态栏纯计数 |
| 3 | 调覆盖度全局默认 + 上限 | 可选 | 默认 全面/256 |
| 4 | 调按逻辑类型 F0-F4 | 可选 | 三层优先级 本信号>逻辑类型>全局 |
| 5 | 点信号看展开链+真值表 | 语义上必需 | 期望本应 designer 手填，不填静默 auto_out 兜底 |
| 6 | 手填期望/加列/负向 | 可选 | 即存盘 |
| 7 | 预览选中.sv | 可选 | 状态栏计数 |
| 8 | 导出 .sv…→选项→文件 | 必 | 重复标号先 warning |
| 9 | 导出报告 | 必 | Topout 只 HTML/CSV；Excel 报告只有 legacy 有 |
| 10 | 回填 for_test | 可选 | |
最短快乐路径 10 次点击、1 tab + 3 对话框。含探针前缀分支 +14 次、跨 2 台机器。要 designer 真手填期望：一个信号 25 列 → 一张表上百次单元格编辑，**没有批量填/导入期望的通道**。

分支（CUVUNF / 非可建）：A1 导出 nets.txt → A2 离开 GUI 红区跑 scan_rtl → A3 设置探针前缀→导入 probe_prefixes.txt → A4 撞名 RO 用『强制 force 信号』（只 legacy，且对 Topout 后端不接）→ A5 RTL 补充逻辑贴 JSON → A6/A7 级联/尾缀开关（只 legacy，对 Topout/子视图**无效且不提示**）→ A8 导出/导入配置（只 legacy）。

## 7. 违反 gui-feedback 原则
| # | 原则 | 现状 |
|---|---|---|
| 1 | 别加开发者视角提醒 | ❌ 级联说明窗永远显示「仓库根目录没找到该文件」（找 <repo>/级联模式说明.md 实际在 docs/）；6 处 tooltip 写 CLI 命令；on_load 出错把 traceback 塞 .sv 预览页「请把下面发给维护者」 |
| 2 | 跳过内容必须可见（名字+原因） | ❌ SV 五视图『导出 .sv…』只弹纯计数 + 记账名字无原因、无 setDetailedText；legacy on_generate 合规 |
| 3 | 信号名+原因 > 数量 | ❌ SV 预览/导出/状态栏全纯数字 |
| 4 | 编辑器不塞模板行 | ✅ |
| 5 | 可复用配置支持导入导出 | ⚠ 导出/导入配置只在 legacy；强制 force 编辑器无导入导出 |
| 6 | IC 工程师语言 | ✅ |
| 7 | 真值表行表头用真名，字母对照放 tooltip 和『输入信号』表 | ❌ SV 没有『输入信号』表，无处查某输入 RO/RW、force/RF_WRITE |

另三条事实：
- 6 组开关（logic/mux 级联、logic/mux 加尾缀、缺前缀强制生成、强制 force、本信号探尾缀网、本信号级联）只在 legacy，且只作用于 legacy 导出；_TopoutProvider 建 Resolver 不传 cascade_mode/append_to_*/force_overrides/suffix_override；topout.py include_risky=True 写死(L961/L1307)，pageviews cascade_mode="force" 写死(L59)。用户在 legacy 改了开关切回 Topout 导出，不生效且不提示。
- 两个『导出 .sv 选项』默认值不同却共用 settings 键。
- 1600px 宽时 splitter 默认 [440,760]，信号表只露到 owner，**状态/用例 两列默认看不到**。
