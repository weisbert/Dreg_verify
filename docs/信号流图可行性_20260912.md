# 信号流门级图 — 可行性与选型调研（2026-09-12）

> 需求原话：「增加一个信号流层级的图；一个信号从源头到 topout，画出 NAND/OR/MUX 等逻辑组成的实际电路图，配上各线上的 net 名称。」
> 调研方式：只读，实跑 `analyze_signal` dump 两张 mirror 表 21 个 Topout 信号；原型脚本与样图在本地 `refactor_notes/sigflow_proto/`、`refactor_notes/gui_v2_screens/`（gitignored）。仓库零改动。

## 0. 一句话结论

**画得出来，且不需要动 cone/expr 的核心逻辑。** 主路线用「结构路线」（从 `MuxGroup` / `res.expansion` / `LogicSignal` 建图），AST 只用来画 logic 行内部的布尔式；纯 AST 路线会因 cone 代入的子树复制和 mux 的比较链展开膨胀 3~10 倍，且中间层 net 名在 AST 里已被抹掉。仓库侧最小改动 = 4 行（cone/synthesize 返回子树根挂 `origin_net`，实测可行且 byte-safe）。渲染选自写 SVG 生成器（本机与公司机都没有 graphviz 二进制，也没有 networkx/matplotlib/schemdraw）。

## 3. AST → 图元映射

| AST / 模型 | 图元 | 标注 |
|---|---|---|
| Ternary(c,t,e) | MUX2 | S=cond 顶边；1=then、0=else；输出标 net+位宽 |
| 连续 Ternary 同 sel 的 `(sel&care)==cv` 链 | MUXn | 每支标 case 字面量含 don't-care；末支 default |
| MuxGroup（结构路线） | MUXn | S=各控制拼接（多控制 BUS-MERGE 进 S）；每支标 case_raw + Excel 行号 |
| `&` / `|` / `^` / `~^` | AND / OR / XOR / XNOR（~ 合并成 NAND/NOR 气泡） | |
| `~` / `!` | NOT 气泡 | |
| 归约 | REDUCE 块 | 输出 1bit |
| 比较 | CMP 块 | 右操作数常量直接写在块上 |
| 移位/算术 | 功能块 + 算子文字 | |
| Concat / Repeat | BUS-MERGE 梯形 | 每支标占位段 |
| Part | BUS-TAP 小三角 | [msb:lsb] |
| Var + RW | REG 盒 | 名 / RW @addr[msb:lsb] / 宽 |
| Var + RO 有地址 | 线控寄存器盒 | RO @addr，force |
| Var + wire/needs-prefix/prefixed-wire | PIN 盒（虚线框） | force <wire> + 角标「名字来自命名约定，表里未查到」 |
| res.dft_gate | GATE 盒（AND + iddq 气泡） | iddq ? 0 : inner、门网名、透传值 |
| root.renamed / _ls | RENAME / LS 透传块 | 左源名、右顶层口名 |
| Topout 根 | TOPOUT 端子 | name[msb:0] |

### 中间层 net 名怎么标回去（推荐方案 A，4 行，已实测）
在 cone/synthesize 返回子树根挂 `origin_net/origin_kind/origin_width/origin_row`。可行依据：expr.py AST 类无 `__slots__`（只有 Token 有）；cone._substitute 按引用嵌入子树，属性活得过上层代入；原型从 tx_epa 最终 AST 取回 7 处 origin_net，深度与 net 名全对。
byte-safe：全仓对 AST 无 deepcopy/pickle；下游（vectors/forms/sv_writer/gui）一律 isinstance + 结构字段 → 6 sha 不变。

方案 B（二期，~20 行）：`cone.expand` / `synthesize_mux_expr` 加 `graph_out=None`，与 `chain_out=` 对称，在真实遍历里吐分层边表，永不与 cone 判定漂移；要同步 3 处回退清理。

## 6. MVP / 完整版

### MVP（一轮，覆盖两张 mirror 21/21）
- 新模块 `dreg_verify/sigflow.py`（纯函数，只依赖 expr/cone/mux_gen/forms/resolver，不 import PySide6）：`build_graph(wb, resolver, result) -> Graph`（结构路线为主）+ `render_svg(graph) -> str`。
- 仓库改动只要 A + A′ + C。B/D/E 二期。
- 图元：REG / PIN / AND / OR / NOT / XOR / MUX2 / MUXn(case 标签) / GATE(iddq) / BUS-TAP / BUS-MERGE / RENAME / TOPOUT；归约·比较·移位·算术 = 功能块 + 算子文字。
- 布局：最长路径分层 + DFS 列内序 + 三段正交折线 + 长边 dummy；不做交叉最小化。
- 标注：每线 net 名 + [msb:lsb]；REG 盒 RW @addr[bits]；PIN 盒 RO force <wire>；猜名虚线。
- 出口：GUI「展开链 / 真值表」旁加「信号流图」子页（QSvgWidget + 导出 SVG/PNG）；HTML 报告 detail 段内联 `<svg>`。
- 不做：交互高亮、ANSI 门形、自动分页、MUXn 美化。

### 完整版
- 改动点 B → 图与 cone 判定同源；撞环回退也如实画。
- MUXn 折叠 + barycenter 交叉最小化 + 端口锚定 + ANSI 门形。
- 交互：点线高亮同名网、点寄存器盒跳真值表对应行、hover 出 binding.note。
- **覆盖度叠加**：把当前向量集在图上点亮实际走到的 case 支，没驱动过的涂灰 → 把「假绿」风险画出来。这是图相对真值表的最大增量价值。
- 多信号总览图（一个 owner 一张）+ PDF 导出（QtPdf 已装）。
