## ① 目标 + 现状两条缝

**目标**：3 套并行实现（`generator.build/report` · `topout.*` · `pageviews.*`）合成一条共享流水线
`resolve → expand_full → classify(AST形态) → cover(按形态) → render/finalize`，**覆盖挂在「展开后表达式形态」上、不挂「信号来自哪种门/哪一页」**。入口（Topout/页/CLI/GUI）只决定 anchors + opts，下游全共享。

**两条缝（已 .venv 实测坐实）**：
- **缝A（展开层）**：dft/iddq 不是 cone 一级，是 cone 出来后 `pin_dft_gate`(generator.py:762)/`_append_dft_vectors`(719) **旁路 pin 一根 force**。每条造向量的路都得「记得再 pin」→ MUX 分支/页视图/register 富表三处漏（M1/M2/m2 + xfail）。
- **缝B（渲染层）**：register/dft改名根走 `_topout_probe_block`/`_register_passthrough_block`(706/726) 裸调 render_signal_block，绕过 build 的块顶⚠/owner/claims/负向/fortest 注入圈；`build_for_topout` 返回 dict 只透 5 键、丢 6 通道（M3-M8/owner/claims）。

**收敛点（设计可依赖）**：三套路径最终都调 `sv_writer.render_signal_block`，clean logic 信号三路 **byte-identical**（实测 `d_logic_bt_lp_reserve` 3568B 全等）。cone+expr 是唯一权威展开/求值引擎。

> **⭐分母校正（批判 Q1）**：审计正文权威命名项 = M1–M8(8)+m1–m7(7)+t1(1)=**16 + xfail = 17 个可修项**。审计头「30 候选→28 confirmed」的 11 条差额=多 finder 重复 id，无人认领。本稿只对齐 17 个 finding-id。

## ② ⭐ 形态分类表（keystone）

> AST 节点恰 8 种（实测 expr）：`Const/Var/Unary/Binary/Ternary/Concat/Repeat/Part`。`classify` 纯看节点结构 + bindings 宽度，**不读 wb、不看来源页**。

| 形态 | AST 判据 | 覆盖算法（现有零件） | 边界/陷阱 |
|---|---|---|---|
| **F0 直连寄存器** | 根=平凡 `Var(BASE)` 单叶子 | `generate_vectors`(all0,distinct→恒2条) | 位宽取字段全宽(修裸名只验bit0假绿) |
| **F1 纯布尔/位运算** | 根=Binary/Unary/Concat/Repeat，无选路Ternary | `generate_vectors`(control全组合×data主题) | ⚠control>2bit只取{0,全1}→中间case漏(R5盲区)；切片Part按group_key共享 |
| **F2 选路(单层)** | 根=`Ternary(cond,then,els)` 且 cond 判 control；或原生 MuxGroup | **二分叉**：可展→`synthesize_mux_expr`折Ternary走generate_vectors；不可展(宽select/hole/>2bit)→`make_mux_vectors`选路覆盖 | 互异/反码/穷举；保WL mux金标准逐字节 |
| **F3 门控(gated)⭐** | 根=`Ternary(Var(GATE),Const(常量支),功能子树)`，GATE=`wb.dft[out_base].gate_base` 单1bit | **门维×内层维**：GATE=透传→内层每条挂`extra_forces=[(gate,透传,1)]`；GATE=非透传→**追加1条克隆首条功能拍**(force gate=非透传,release_nets,dft_pitch=True,exp=常量支) | ⚠**内含复刻`_append_dft_vectors`拍序的特判**(见下) |
| **F4 复合(门控套选路/布尔)** | 外层F3，els 递归 classify 为 F2/F1 | `cover_gated = [GATE=透传]×cover(els,内层) + [GATE=非透传,1条克隆拍]` | ⚠**实测WL 5个gated mux中4个不可展→这是常态非边角**；内层不可展时门嫁接在路由向量外=旁路仍在、只收敛一处 |

### ⭐ 门控覆盖的诚实版本（修正「自然长出」话术 — 批判 Q2/Q3）

实测反例（gated logic `d_en_vco_fc_ls`，门 transparent=0）：

| 路径 | 向量数 | 第3条 |
|---|---|---|
| **当前 pin+append（真值）** | **3** | T2=T0**克隆**，`ef=[(gate,1,1)]+release_nets=[gate]+dft_pitch=True`，exp=0 |
| **朴素 form-driven**(generate_vectors 跑 `G?0:(A?C:B)`) | **4** | T2/T3=`assign G=1` 普通赋值，无force/release/pitch→.sv字节全异 |

**结论（写进契约）**：`cover` 的 F3/F4 门控分支**必须内含一段精确复刻 `_append_dft_vectors`/`pin_dft_gate` 的特判**（只克隆首条功能拍、force gate=非透传、release_nets、打 dft_pitch、去重）。**这段特判 ≠「自然长出」——它没消失，是从 generator.build 循环里散落多处的旁路，搬进 cover 门控分支这一处。** 真实收益 = **「旁路收敛到唯一一处、四入口共享」**（不再 M1/M2/m2 各漏各的），**不是 byte-identical 自动成立、也不是消除特判**。byte-identical 保证级别 = **逐字段全等**（assignments/exp/extra_forces/release_nets/dft_pitch/顺序），不是「向量集等价」。

## ③ 统一接口 + 零件归位

```python
def pipeline(wb, anchors, opts) -> PipelineResult:
    for a in anchors:
        root      = resolve(wb, a)                       # 顶层名/页对象→源对象(5分类)
        ast,b,gate= expand_full(wb, resolver, root, opts)# →对叶子完整AST + 门元信息(iddq变Ternary叶子)
        shape     = classify(ast, b, gate)               # →形态(可嵌套 F0..F4)，仅看AST结构
        vecs      = cover(ast, b, shape, out_width, opts) # →向量(按shape派发，绝不按root.kind)
    return finalize(signals, vecs, opts, wb)             # 唯一注入层
# PipelineResult = {blocks, results, claims, warnings{6类}, summary, fortest_rows, view_models}
```

**零件归位**（不是丢弃、是归层）：resolve_root→resolve；cone.expand/synthesize_mux_expr→expand_full；classify_vars→classify底座；generate_vectors→cover F0/F1/F2可展；make_mux_vectors→cover F2不可展/F4内层；**pin_dft_gate+_append_dft_vectors→cover F3/F4分支内部(仍是特判)**；render_signal_block→render底层(不动)；collect_claims/fortest_order_entries/6类⚠注入→finalize(抽source-agnostic)；`_topout_probe_block`/`pageviews.analyze_*`/`topout.analyze_signal三分支`→**删除**，改走流水线。

**入口收口**：`PipelineOptions` = `GenOptions`(48形参)超集 + anchors + cascade，缺键保持当前值不复位(R37续4防污染)。现状 opts 丢失矩阵：topout_view_models丢owner/scope/edit/overrides；report_for_topout丢owner/scope/edit；build_page_sv丢sig_cov/overrides。
